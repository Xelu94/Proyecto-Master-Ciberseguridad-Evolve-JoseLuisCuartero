Análisis por servicio
21/TCP FTP — File Transfer Protocol ▶
  • Sesión anónima (usuario: anonymous, pass: vacía)
  • Versión vulnerable con exploit conocido
  • Credenciales reutilizadas de otros servicios
ftp IP
Conectar — usuario: anonymous, contraseña vacía
nmap --script ftp-anon IP
Detectar acceso anónimo con script NSE
searchsploit vsftpd 2.3.4
Buscar exploit por versión del servidor
💡 Si FTP + puerto 80 activos: subir PHP malicioso por FTP y ejecutarlo desde la web = RCE
22/TCP SSH — Secure Shell ▶
  • Fuerza bruta con credenciales
  • Versión vulnerable
  • Claves privadas expuestas en el sistema
ssh usuario@IP
Conexión directa
hydra -l usuario -P /usr/share/wordlists/rockyou.txt IP ssh
Fuerza bruta de contraseña
nmap --script ssh-brute IP
Fuerza bruta con script NSE
use auxiliary/scanner/ssh/ssh_login
Módulo Metasploit — bruteforce SSH
23/TCP Telnet ▶
  • Protocolo sin cifrado — credenciales visibles en tráfico
  • Credenciales por defecto del dispositivo
telnet IP
Conexión directa
⚠ Telnet no cifra el tráfico. Cualquier sniffer en la red captura las credenciales en texto claro.
25/TCP SMTP — Simple Mail Transfer Protocol ▶
  • Enumeración de usuarios válidos (VRFY / EXPN)
  • Open relay — enviar correo como cualquier dominio
nmap --script smtp-enum-users IP
Enumerar usuarios válidos del servidor
nmap --script smtp-open-relay IP
Detectar open relay
telnet IP 25
Conexión manual para pruebas con comandos SMTP
53/TCP+UDP DNS — Domain Name System ▶
  • Zone transfer (AXFR) — vuelca todos los registros DNS
  • Subdominios por fuerza bruta
dig axfr @IP dominio.com
Intentar transferencia de zona completa
nmap --script dns-zone-transfer IP
Zone transfer con script NSE
dnsrecon -d dominio.com -t axfr
Reconocimiento DNS completo
80/443 HTTP / HTTPS — Web ▶
  • Fuzzing de directorios y archivos ocultos
  • Versión vulnerable del servidor web
  • CGI habilitado — posible Shellshock
  • Información en phpinfo.php, robots.txt, .git/
ffuf -u http://IP/FUZZ -w /usr/share/dirb/wordlists/common.txt -c
Fuzzing básico de directorios
ffuf -u http://IP/FUZZ -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-medium.txt -c
Fuzzing con SecLists (más completo)
nikto -h http://IP
Escáner automático de vulnerabilidades web
curl -I http://IP
Ver cabeceras HTTP — versión del servidor
🔍 Siempre revisar manualmente: /robots.txt · /phpinfo.php · /.git/
139/445 SMB — Server Message Block ▶
  • Enumeración de recursos compartidos anónima
  • Versión vulnerable — EternalBlue (MS17-010)
  • Credenciales débiles o reutilizadas
smbclient -N -L //IP/
Listar recursos compartidos sin credenciales
smbclient //IP/recurso -N
Conectar a recurso sin credenciales
enum4linux -a IP
Enumeración completa SMB / NetBIOS
nmap --script smb-vuln-ms17-010 IP
Detectar EternalBlue
use auxiliary/scanner/smb/smb_version
Módulo Metasploit — versión SMB
3389/TCP RDP — Remote Desktop Protocol ▶
  • Fuerza bruta de credenciales
  • BlueKeep — CVE-2019-0708 (pre-auth RCE)
  • Credenciales reutilizadas de otros servicios
nmap --script rdp-enum-encryption IP
Detectar cifrado y versión de RDP
nmap --script rdp-vuln-ms12-020 IP
Detectar vulnerabilidad DoS MS12-020
hydra -l Administrator -P wordlist.txt IP rdp
Fuerza bruta RDP
xfreerdp /u:usuario /p:contraseña /v:IP
Conexión RDP desde Linux
3306/TCP MySQL / MariaDB ▶
  • Acceso sin contraseña (root sin pass)
  • Credenciales por defecto
  • Inyección SQL desde otra capa de la app
mysql -u root -h IP
Conexión sin contraseña
nmap --script mysql-empty-password IP
Detectar acceso sin contraseña
nmap --script mysql-info IP
Información general del servidor MySQL
